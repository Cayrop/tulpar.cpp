# Ops Directory

Operational safety artifacts for Phase-0.5.

## Structure

- `bin/` — Operational scripts (status, capture, start, stop, health)
- `legacy/` — Preserved launch scripts from /tmp/opencode/
- `run/` — PID files and runtime state
- `logs/` — Log directory for future use
- `manifest/` — Flag manifests and capture records
- `templates/` — Command templates
- `measurement/` — Measurement window plans
- `pidfile_policy.md` — Pidfile convention and rules
- `phase05_report.md` — Full Phase-0.5 report
